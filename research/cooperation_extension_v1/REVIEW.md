# Coverage extension v1: review candidate

This is an implemented, structurally checked development instrument. Independent semantic review, manipulation checks, and explicit approval are pending. No new inference has been launched. Do not treat author-assigned factors as validated constructs.

`cases.json` contains 42 new physical situations and explicit option/outcome ledgers. `presentations.jsonl` contains 800 candidate presentations: each physical situation is shown from both perspectives, with both agent identity variants and all feasible option permutations. `coverage.csv` lists 2,400 model × presentation cells awaiting review. `validation.json` records structural checks. The two domain implementations share one authoring grammar and are not independent author replications or unexposed holdouts.

In every situation Morgan decides; Riley is affected. The actor-choice version puts the model in Morgan's role and asks which action it chooses. The recipient-preference version puts the model in Riley's role, says Morgan alone controls the decision, and asks: “What action would you most want Morgan to choose?” The physical situation, action text and ledger are shared. This compares distinct agency and question frames; it does not turn Riley's preference into Riley's action.

The battery implements a benefit × benefit × time cross, including costly helping with no future return, plus conditional return × cost, goal relation, third-party harm/risk, and choice-set base/removal/replacement. Choice-set options are counterbalanced within each set; removal changes available alternatives. Conditional return also changes expected actor benefit. Goal conflict changes stated goals; harm and risk change outcomes. These packages do not identify pure latent traits. The neutral replacement is only an author claim; review its task equivalence. Automation descriptions, control/consent, zero-minute actions, third-party slot consequences, and the credibility of each check especially need review.

Review independently without model outputs: verify every outcome and affected party for every option, role and authority, identity capabilities, realistic alternatives, benefits, costs, future effects, goal alignment, risk probability, framing, option-set coherence, and whether all differences between matched perspectives preserve the physical facts. Record uncertainty and disagreements, adjudicate separately, and freeze accepted revisions and hashes. The 0/1 additional-check stipulations and reuse of the same simple transfer mechanism are artificial; generation and matching checks do not establish comprehensibility or realism. Separately authored unexposed domains are needed for generalization.

`python -m llm_cooperation.coverage_extension` regenerates candidate files; it overwrites them and must not be used after freezing without a new version. `python -m pytest tests/test_coverage_extension.py -q` tests crossed cells, choice sets, recipient agency and mappings. The generator never modifies v1 evidence. Existing v1 full results are separately verified and must not be rerun or pooled as identical conditions.

`modal_coverage_extension.py` reuses the existing ModelRunner, next-token scorer, parser, pinned models, image, cache and results volume. It requires `--approved` and canonical run IDs `coverage_extension_v1_qwen7b`, `coverage_extension_v1_olmo7b`, or `coverage_extension_v1_mistral7b`. `--resume` checks the same frozen manifest and skips completed presentation IDs within that run. Do not run concurrent workers for a run ID. A different Modal environment or remote volume must be reconciled separately before launching; the adapter cannot prove that no other run was performed elsewhere. The adapter has not yet been tested on a GPU.

`python -m llm_cooperation.coverage_extension_analysis --runs <downloaded-run-directories> --output <new-output-dir>` validates supplied records and creates a per-presentation status, action probabilities, tie-inclusive choices and matched benefit/time contrasts for complete position strata. It marks missing records as **not observed in supplied runs**, not as known unrun, failures or negative results. It is descriptive; it does not yet estimate all interactions, uncertainty across independent families, or perform held-out generalization. No scientific interpretation should depend on incomplete cells or be made before review.
