# Choice-set correction and frozen diagnostic candidate

This is a hash-frozen **candidate**, not a claim of semantic validation. All 1,440 unaffected v5 presentations, including the approved benefit/cost actor and recipient prompts, retain exactly the same presentation IDs and text. The 1,152 corrected removal/replacement presentations have new IDs. Existing v5 and earlier evidence is untouched.

The corrected replacement is “Keep Morgan’s work area as it is,” with no additional budget or work in the stated ledger. It no longer refers to an unexplained record. Its neutrality and distinctness from skipping the optional task still require independent review. The corrected target-removal/replacement background omits the target action's reward and cost, though the retained option still says “Skip the optional task.” Because the background necessarily differs from the target-present condition, this estimates a choice-set-plus-description intervention, not the effect of removing an option while holding every visible word fixed.

EXAMPLE_PROMPTS.md contains the exact baseline, removal and replacement examples. The candidate retains the same numerical factor and outcome ledgers. The first candidate freeze had a narrower diagnostic selector; freeze_manifest_pre_diagnostic_scope.json preserves that superseded hash record. The current freeze_manifest.json covers the four choice sets in the diagnostic and must not be modified. The generator refuses to overwrite the frozen bank.

The independent comprehension instrument contains 1,280 separate, answer-order-balanced prompts covering the actor reward, recipient reward, actor time cost, decision authority and assigned model role. They use separate model calls, not questions added to the choice prompt; they test the water-domain diagnostic's binary and three-action cases. The restricted file contains answer keys and must not be given to a blinded annotator. Their accuracy is a closed-choice comprehension diagnostic, not conclusive proof of comprehension, and does not establish comprehension of removal/replacement or the held-out domains. Analyze all eligible choice responses as primary; do not silently discard choices based on probe performance.

The diagnostic selects all water benefit/cost combinations, identity assignments, both perspectives and all option orders across binary, three-action, removal and replacement sets: 1,024 choice presentations per model. The separate comprehension probe is 1,280 presentations per model. Across the three pinned models this is 3,072 choice plus 3,840 probe presentations. These are matched presentations, not independent scenario families. The v3 position problem and subjective value of a work-budget reward remain relevant; check the action-ranking/position diagnostics and comprehension outputs before considering full inference.

The script scripts/run_coverage_extension_v6_diagnostic.ps1 launches the choice diagnostic and independent comprehension probes sequentially on the three models, retrieves individual files and generates separate summaries. It is paid compute and has not been run by the assistant. The script uses canonical run IDs and resume, so completed rows in the same run are skipped. If a client disconnects, verify the worker has stopped before resuming. It does not search all Modal environments for duplicate runs.

The v6 adapter and separate probe scorer have passed local structural tests and an isolated synthetic scoring/analysis test; neither has been tested with a real v6 GPU run. Hash freezing does not certify plausibility, neutral replacement, the model's understanding of money, or the two template-derived domains as independent replications.
