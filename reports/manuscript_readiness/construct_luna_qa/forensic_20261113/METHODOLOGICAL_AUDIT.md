# Qwen–Luna construct pilot: forensic and methodological audit

## Scope and result

This is an offline, exploratory audit of the existing 280 synchronous Luna responses and preserved Qwen classifications. Ten deliberately selected development packets yield 40 scenario-version/wording combinations and seven fields each. These are not 280 independent scenarios. No new model inference was launched; no historical label or manuscript was changed. The behavioral experiment and classification behavior are distinct.

The importer reports 265 `format_valid`, 12 `review_needed`, and three `error`; 82/265 format-valid records agree exactly (30.9%). The percentage is a descriptive comparison between two model outputs with different prompts, not classification accuracy or an estimate for the 152-template corpus. The 12 quote-flagged records have usable label responses; sensitivity summaries include them. The three errors are valid completed API responses with two goal labels, rejected by the local importer because it requires a single answer. They are not three failed API calls. Raw multiple answers remain in `analysis.json` under `schema_errors`.

Input packet, classification, mapping, and request hashes matched the saved manifest, and all 280 unique response IDs map to one prepared request. Each Qwen label was checked against the original classification record and each mapped scenario/action against the packet. This verifies the local join, not that either model understood the text. Hashes are in `analysis.json`. No assertion is made about independently verifying external service execution from files alone.

## Are the tasks actually equivalent?

**No, not fully.** Both assess the same scenario, counterpart version, focal wording and independent reference action; the mapping preserves original/paraphrase source identity. But Qwen saw the two target wordings together, the reference, and two additional alternatives, with blocks reordered. Its prompt inaccurately says “two target alternatives” each have two phrasings, although one focal action has two. Luna saw one wording and only the target/reference comparison per call, with explicit actor and counterpart roles. The focal target is identified in both; neither task fully blinds which option is under study. Qwen's prompt lacks Luna's explicit third-person guidance. Some scenarios use third-person narration and leave the actor underspecified, so even explicit role instructions do not resolve every case.

The exact field strings are shared, but the **decision criteria differ**. Qwen's interaction rubric lists categories with little definition; Luna additionally asks what is supported and allows several labels. Qwen's interdependence rubric speaks about contributions; Luna's says assess whether “contribution by multiple agents is necessary” for the target action. In `RV-223472_A_w1`, Luna explains that a choice described as joint *requires joint participation*, while Qwen chooses beneficial-but-unnecessary. That is not automatically a dispute about whether the same underlying boundary-survey objective can be achieved independently.

For outcomes, Luna explicitly requires a comparable **overall** outcome for `equal` and uses `unclear` for missing or mixed dimensions. Qwen is told to compare outcomes and avoid equal from silence, but is not given Luna's overall-outcome criterion. Thus matched speed or accuracy could legitimately lead to a dimension-specific equality judgment under one policy and global uncertainty under another. Neither schema records which dimension is being ranked. A positive stated target consequence does not prove it is superior to a reference whose consequence is unstated; for example, `RV-223472_A_w1` Luna describes prevention of encroachment as a benefit and notes no comparable reference benefit is stated. This is a candidate absence-of-evidence error, not an adjudicated correction.

The goal field is a single exclusive choice despite common broad shared goals and distinct immediate goals. Three Luna responses select both `shared` and `compatible_distinct`; the JSON schema permits arrays of any length, while the importer rejects multiple values for all fields except interaction. Two explicitly contrast target and reference. This is a **schema/policy mismatch**, not necessarily an incoherent answer. The interaction field is legitimately multi-label; the other fields are forcibly single-label locally. Opportunity cost conflates unobserved risk, possible foregone benefits and actual cost; `none_stated` is not proof of no cost. Lexical favor lacks anchored examples and can be read as overall normative attractiveness or wording-specific skew. These design choices can create disagreement even with shared factual understanding.

## Quantitative description

The following is format-valid only. Agreement is exact set agreement; kappa is nominal Cohen's kappa across repeated records, with Qwen and Luna as raters. Kappa is sensitive to label prevalence and is not accuracy. For interaction, kappa treats each entire label set as one nominal category, not independent subtype tags. `field_metrics.csv` includes a 2,000-resample percentile interval for exact agreement by resampling **packets**, not presentations; with only ten selected clusters it is unstable and does not support generalization. `including_quote_flags` gives a sensitivity view, not verified correct quotes.

| Field | Valid / 40 | Exact agreement | Cohen κ |
|---|---:|---:|---:|
| Interaction sets | 39 | 28.2% | 0.211 |
| Interdependence | 40 | 50.0% | 0.307 |
| Goal structure | 35 | 48.6% | 0.106 |
| Actor outcome | 35 | 20.0% | 0.021 |
| Counterpart outcome | 36 | 33.3% | 0.143 |
| Actor cost | 40 | 22.5% | -0.003 |
| Lexical favor | 40 | 15.0% | 0.056 |

For interaction, mean per-record Jaccard overlap is 0.528 across 39 usable sets. Treating Qwen tags purely as a **comparison reference**, not truth, Luna's micro precision is 0.574, recall 0.636, and F1 0.603. These are directional label-overlap metrics, not diagnostic sensitivity or accuracy. Category-specific overlap and Qwen-only/Luna-only counts are in `interaction_metrics.csv`; the full directed matrices are in `confusion_matrices.csv`.

Illustrative directional disagreements among valid records: Qwen `equal` versus Luna `target_better` for actor outcome occurred 10 times; Qwen `equal` versus Luna `unclear` for counterpart outcome 10; Qwen `opportunity_cost` versus Luna `none_stated` 11; and Qwen `balanced` versus Luna `target` lexical favor 30. Counts repeat wordings and partner versions; none identifies the correct answer. At the packet level, disagreements range from 10/25 to 24/26 usable fields; `packet_disagreements.csv` records bank and denominator. The selection was not designed to compare banks statistically.

Within partner, original-versus-paraphrase labels agree in 138/140 Qwen and 97/137 available Luna field comparisons, pooling fields. Matching human versus AI within source wording gives 98/140 Qwen and 94/138 Luna. These are descriptions of model self-consistency, not a requirement that variants always agree: partner capabilities or text can differ. Qwen saw wordings together, whereas Luna evaluated them separately, making the difference in stability especially uninterpretable as model superiority. All item-level comparisons are in `analysis.json`.

## Evidence quotations and original corpus

There are 736 supplied Luna evidence entries: 724 exact in the declared source, 11 absent verbatim from all three source fields, and one exact in a different source field. The 12 importer-flagged records correspond to these 12 evidence entries. Eight share the paraphrase “the text is destroyed beyond recognition”; the actual stem says “the text being destroyed beyond recognition.” This is a model-generated nonverbatim quotation, not evidence that the source text was missing. One quote attributed to `target` appears verbatim in the `scenario`. The other three are nonverbatim phrases, including shortened or merged wording. `quote_review` retains each string and its automated category. We cannot infer intent or establish semantic support merely by checking strings. The original source also contains awkward or incomplete wording, and some contexts leave reference consequences or actor authority unspecified; candidate cases require adjudication rather than repair in place.

## Corpus coverage and future analysis

The Qwen output has 608 version/wording judgments from 152 bank-specific templates: Phase 0 240, Phase 0B 248, Phase 1 120. `corpus_assignments.csv` and `corpus_cooccurrence.csv` count **Qwen-assigned labels**, not verified prevalence. Multi-label totals overlap and variants are repeated. Qwen tags timing coordination 221/608, information sharing 192/608, joint task 119/608, parallel activity 112/608, unilateral help 54/608, resource sharing 53/608, exchange 20/608, and unclear 18/608. The count of exchange labels is not a validated measure of reciprocity. The most common labeled pair is timing coordination with information sharing (48 judgments). Category distributions by bank and all pair counts are provided, but cannot be interpreted as corpus construct prevalence without adjudication.

Qwen labeled interdependence `necessary` only 22/608 and `beneficial_not_necessary` 403/608; these assignments are especially questionable in light of the pilot and differing definitions. Goal, cost, and outcome label distributions by bank are in the CSV; they cannot establish how much real sacrifice or shared purpose the corpus contains. The paired pilot join already matches each scenario, partner, wording, and four position rotations to choice outcomes in 11 responsive base checkpoints. Once labels are independently assessed, one can examine model-specific within-bank, subtype-conditioned forced-choice margins, preserving packet/triad clustering, wording, partner identity, ties and label uncertainty. Such analyses are post-hoc and observational; a classification label is not an experimentally randomized property, and overlapping subtypes and sparse categories complicate comparisons. Family sizes are not independent replications. A label does not establish stable preference across choice sets, and comparing action labels with observed next-token choices is not direct measurement of altruistic motivation.

Existing three-option removal runs can support a separately checked, conditional comparison with the four-option assay where the matched cases and coverage are verified, but removal changes the alternatives and cannot reveal the original second preference. This audit has not verified row-level joins for that follow-up. New controlled, independently reviewed scenarios would be needed to separate interdependence, cost, counterpart benefit, reciprocal contribution, and lexical appeal causally or test generalization across new settings. Several fields here vary jointly by design or are unspecified.

## Adjudication priorities and next work

1. Review the ten full packets with `BLIND_REVIEW_GUIDE.md`; the blank responses cover all 280 judgments, including agreements and exclusions. Give the two reviewers independent copies. `comparison_key_RESTRICTED.json` links both model outputs and evidence **only after** the first pass. These materials are model-output-blind but identify the focal action, and the participant type may be obvious.
2. Prioritize candidate unsupported opportunity costs, apparent inference of an advantage from an unstated reference, broad shared versus distinct goals, necessary action participation versus task interdependence, overlapping subtypes, and lexical framing. These are hypotheses for review, not predetermined verdicts. Inspect both target/reference source text and alternate wording.
3. Revise the taxonomy into independent dimensions: who contributes, whether success requires joint contributions, coordination in time, stated outcome changes by party and dimension, realized versus possible/opportunity costs, goal alignment and framing. Permit multiple goals and `mixed`/`unknown`. Freeze instructions and examples before reviewing new data.
4. Use independently reviewed examples beyond the development cases to estimate field-level support, uncertainty, false accept/reject patterns, and reviewer disagreement. Design corpus balancing around templates, not repeated variants; only then evaluate category-conditioned behavior and consider new controlled contrasts. The current ten-packet sample is neither a gold set nor a population estimate.

Reproduce from repository root with `python scripts/audit_luna_construct_pilot.py`. It writes only this derived directory and re-creates its outputs. Tests: `python -m pytest tests/test_audit_luna_construct_pilot.py -q`. Do not edit the inputs to correct findings; record adjudications separately.
