# Phase 1 provisional observational results

These are **pre-human-semantic-adjudication exploratory observations**, not a completed prospective confirmatory replication. Each checked run records its original bank SHA-256 and the explicit provisional research status.

The legacy `llm-coop analyze` utility labels some outputs `Phase 0`, `Phase 0B`, `confirmatory`, or `FORMAL REPLICATION TEST` based on scenario metadata; **these legacy labels do not upgrade the scientific status of this dataset**.

The cohort_summary.csv rates are descriptive presentation-level proportions; repeated Latin-square presentations of the same scenario are not independent samples. Consult scenario/template-clustered analysis and protocol for inference.
